# Library Management System

Projekt zaliczeniowy z programowania obiektowego i funkcyjnego napisany w języku Python.

## Opis projektu

Aplikacja umożliwia obsługę biblioteki z podziałem na role użytkowników:
- czytelnik,
- bibliotekarz.

Program działa w konsoli i pozwala na:
- logowanie użytkowników,
- przeglądanie katalogu książek,
- wypożyczanie książek,
- przedłużanie wypożyczeń,
- rezerwowanie niedostępnych książek,
- filtrowanie i sortowanie katalogu,
- wyświetlanie statystyk biblioteki.

## Zastosowane zagadnienia

### Programowanie obiektowe
- klasy i obiekty,
- dziedziczenie,
- enkapsulacja,
- polimorfizm,
- właściwości (`@property`).

### Programowanie funkcyjne
- `lambda`,
- `filter()`,
- `map()`,
- `sorted(..., key=lambda ...)`,
- list comprehensions,
- dict comprehensions,
- funkcje wyższego rzędu.
